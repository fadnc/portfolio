# Fadhil Muhammed N C — Portfolio

Static, single-page portfolio built with HTML, CSS, and vanilla JavaScript.

## Local preview

Run `npx serve .` from this directory.

## Deploy

Deploy the project root to Vercel with the Other framework preset and no build command.

## Sharing image

Add a real 1200 × 630 image at `assets/og.jpg` before sharing the portfolio widely. No social preview image has been supplied, so the site currently references this path as a placeholder.
