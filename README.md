# Fadhil Muhammed N C — Portfolio

Static, single-page portfolio built with HTML, CSS, and vanilla JavaScript.

## Local preview

Run `npx serve .` from this directory.

## Deploy

Deploy the project root to Vercel with the Other framework preset and no build command.

## Sharing image

Add a real 1200 × 630 image at `assets/og.jpg` before sharing the portfolio widely. No social preview image has been supplied, so the site currently references this path as a placeholder.

## Interactive design notes

The portfolio uses native HTML, CSS, Canvas 2D, and JavaScript. The hero's perspective glass-bar helix, scroll response, pointer wake, and optional pentatonic notes are an original lightweight interpretation of ideas in [The Endless Glass Xylophone](https://github.com/Sujenphea/xylophone). No source code or third-party runtime from that project is bundled here.

The remaining motion studies use CSS and browser APIs: scroll reveals, a progress rail, project filtering and pointer depth, diagram-like project artwork, and a sticky experience timeline. Reduced-motion preferences are respected.
